# ExMachina — 通用安装指令（任意 AI 工具）

> 用法：对任何支持自定义指令 / 规则 / 系统提示的 AI Agent 说「读取 `<ExMachina仓库>/install/generic.md` 并执行安装」，Agent 即可自主完成。

以下是给 Agent 的执行指令。

## 目标

把本仓库的 `AGENTS.md` 安装为当前工具的常驻指令。你的工具可能不在专用安装列表（codex / claude-code / opencode / cursor / gemini-cli / windsurf / trae / kiro / vscode-copilot）中，按本指令探测接入点。

## 步骤

1. **定位源**：本仓库根目录 = 本文件所在目录的上一级。读取 `<仓库根>/AGENTS.md` 全文备用。
2. **探测接入点**，按优先级取第一个命中项：
   - 项目根已有的指令文件：`AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、`.windsurfrules`、`.github/copilot-instructions.md` 等。
   - 工具全局配置目录下的同名指令文件（`~/.` 下的工具配置目录）。
   - 工具设置中的自定义指令 / System Prompt 字段（此类无法写文件，走第 4 步的手动路径）。
3. **写入**（对可写文件）：
   - 目标文件不存在 → 创建并写入受管理块。
   - 已含 `EXMACHINA:BEGIN` 标记 → 向用户确认更新或放弃。
   - 存在且无标记 → 末尾追加受管理块，保留原内容。

   ```markdown
   <!-- EXMACHINA:BEGIN（请勿在块内手动修改；卸载时删除整个块） -->
   （<仓库根>/AGENTS.md 全文原样嵌入）
   <!-- EXMACHINA:END -->
   ```

4. **手动路径**（工具只提供设置界面入口时）：把 `AGENTS.md` 全文完整输出给用户，指引用户粘贴到对应设置项，并明确告知这一步无法代劳。
5. **验证**：可写文件读回确认标记成对、内容与源一致；手动路径请用户确认已粘贴。
6. **汇报**：接入点、方式（文件 / 手动）、回退方法、生效条件（通常需新会话）。

## 卸载

删除目标文件中的整个受管理块；若文件是安装时新建且删块后为空，则删除整个文件。

## 偏差处理

探测不到任何接入点时，停止动作，向用户列出已检查的位置并询问接入方式，不得静默选择非常规位置写入。
